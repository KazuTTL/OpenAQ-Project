## 3. Cac buoc da thuc hien hop nhat vao `OpenAQ-Project-Unified`

1. **Sao chep bo khung day du tu `feature-ml-analytics`**:
   - Ke thua toan bo luong ETL cua main va cac cai tien thuat toan ML, cac file migration, cac file unit tests.
2. **Tich hop thu muc `analytics/` tu `feature-tv3-analytics-dashboard`**:
   - Sao chep `air_quality_dashboard.pbix` (Power BI).
   - Chuan hoa `queries.sql`: Chuyen dieu kien `WHERE f.is_anomaly = 1` sang `WHERE f.is_anomaly = TRUE` phu hop voi kieu du lieu `BOOLEAN` cua PostgreSQL.
3. **Hop nhat `requirements.txt`**:
   - Ket hop day du cac thu vien: `apache-airflow`, `boto3`, `fastparquet`, `psycopg2-binary`, `sqlalchemy>=1.4.28,<2.0`, `python-dotenv`, `scikit-learn`, `matplotlib`, `seaborn`, `pytest`.
4. **Cau hinh moi truong**:
   - Khoi tao file `.env` tu `.env.example`.
5. **Tich hop pipeline lien hoan trong `src/pipeline.py`**:
   - Bo sung tham so `with_ml=True` vao ham `run_full_pipeline`. Khi chay truc tiep tu Terminal bang lenh `python -m src.pipeline`, he thong se thuc thi lien hoan:
     Phase 1 (Extract) -> Phase 2 (Transform 7 buoc) -> Phase 3 (Load DWH) -> Phase 4 (ML Analytics).
6. **Kiem tra toan ven**:
   - Chay kiem tra cu phap Python (`py_compile`) tren tat ca cac file trong `OpenAQ-Project-Unified`: 100% file deu hop le va khong co loi cu phap.
