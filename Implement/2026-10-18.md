# Báo cáo tiến độ và trạng thái dự án (Ngày 18/10/2026)

## 1. Thông tin chung
- Tên đề tài: Xây dựng hệ thống Data Warehouse và ETL phục vụ phân tích chất lượng không khí từ dữ liệu OpenAQ
- Phạm vi áp dụng: Khu vực Việt Nam (mã quốc gia: VN), tập trung các trạm đo tại Hà Nội, TP. Hồ Chí Minh, Đà Nẵng
- Nguồn dữ liệu: OpenAQ REST API v3 (https://api.openaq.org/v3)
- Công nghệ lưu trữ và xử lý:
  - Object Storage: MinIO (giả lập chuẩn Amazon S3 API)
  - Data Warehouse: PostgreSQL 15 (mô hình Star Schema)
  - Điều phối luồng ETL: Apache Airflow (chế độ LocalExecutor)
  - Trực quan hóa dữ liệu: Apache Superset / Power BI Desktop
  - Ngôn ngữ lập trình: Python 3.10+

## 5. Các lỗi, hạn chế và điểm nghẽn hiện tại (Known Issues & Gotchas)

### 5.1 Lỗi 401 Unauthorized khi gọi trực tiếp OpenAQ API v3
- Hiện tượng: Khi gọi API `https://api.openaq.org/v3/locations?iso=VN`, server trả về `401 Unauthorized: A valid API key must be provided in the X-API-Key header`.
- Nguyên nhân: OpenAQ phiên bản v3 bắt buộc phải truyền API Key, trong khi file `.env` hiện đang để trống `OPENAQ_API_KEY=`.
- Giải pháp đã triển khai: Trong `src/extract/openaq_client.py`, đã cài đặt sẵn cơ chế tự động Fallback sang dữ liệu mẫu thực tế của Việt Nam khi gặp lỗi 401, giúp toàn bộ pipeline kiểm thử không bị gián đoạn.
- Hành động kế tiếp: Người dùng cần điền key thật vào `.env` để pipeline chuyển sang chế độ thu thập dữ liệu trực tiếp.

### 5.2 Môi trường Python cục bộ ngoài Docker
- Hiện tượng: Môi trường máy chủ hiện có sẵn Python 3.11 với `pandas` và `requests`, nhưng chưa cài đặt các gói như `psycopg2-binary`, `boto3`, `scikit-learn`, `apache-airflow`.
- Lưu ý:
  - Khuyến nghị chạy toàn bộ qua Docker Compose (`docker compose up -d`) vì tất cả thư viện và dịch vụ đã được đóng gói sẵn trong container.
  - Nếu muốn chạy trực tiếp mã nguồn trên máy thật (không qua container), cần chạy lệnh `pip install -r requirements.txt`.

### 5.3 Kết nối Database và Object Storage phụ thuộc Docker
- Các lớp `DBConnector` và `S3Writer` kết nối mặc định tới `localhost:5432` và `localhost:9000`. Các cổng này sẽ mở khi người dùng bật container Docker lên.
